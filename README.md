# سجل الخريجين — تطبيق ويب تقدمي (PWA)

المعهد الوطني للعلوم الإدارية — فرع إب. يعمل دون اتصال، ويُثبَّت على الهاتف والحاسوب، وتُحفظ البيانات على الجهاز نفسه (IndexedDB).

## المزايا
- بحث عربي ذكي: يتجاهل الهمزات والتاء المربوطة والياء/الألف المقصورة والتشكيل، ويقبل كلمات الاسم بأي ترتيب.
- تصفية حسب التخصص والدفعة وعام التخرج والتقدير والجنس وجهة العمل، وترتيب متعدد، وصفحات من 50 سجلاً.
- إضافة وتعديل وحذف (مع «تراجع»)، واقتراح التقدير تلقائياً من المعدل.
- إحصاءات تفاعلية (اضغط أي شريط لعرض سجلاته).
- تدقيق البيانات: بدون رقم أكاديمي/شهادة، أرقام مكررة، أسماء متطابقة، تقدير لا يطابق المعدل، ملاحظات «التأكد/مكرر».
- استيراد CSV / JSON / Excel، وتصدير CSV / Excel / نسخة احتياطية JSON، وطباعة.
- مظهر فاتح وداكن، تثبيت، إشعار بالتحديثات، مؤشر انقطاع الاتصال، اختصار «/» للبحث.

## الهوية البصرية
- رأس الصفحات: شعار الجمهورية وشعار المعهد والعنوان الذهبي وبطاقة النظام (الملفان `img/emblem.png` و`img/seal.png` مقصوصان من لقطتك).
- التذييل: التوقيع الإلكتروني «Dr.Salah Al-Ahdal — Design & Development». يستخدم خطي Amiri وGreat Vibes من Google Fonts؛ يُحمَّلان عند أول تشغيل بالإنترنت ثم يُخزَّنان للعمل دون اتصال (وبدونهما يظهر خط بديل).
- المظهر الافتراضي داكن كحلي وذهبي، ويوجد مظهر فاتح من زر ◐.
- لتعديل النص: ابحث في `index.html` عن `class="foot"` و`class="hero"`.

## التشغيل محلياً
```
cd nias-alumni-pwa
python3 -m http.server 8080
```
ثم افتح http://localhost:8080 (الـ Service Worker يعمل على localhost أو HTTPS فقط).

## النشر (مطلوب HTTPS ليظهر زر التثبيت)
ارفع المجلد كما هو إلى أي استضافة ثابتة: Cloudflare Pages أو Netlify أو GitHub Pages أو Firebase Hosting.

## استيراد بيانات الخريجين
1. صدّر ملف Excel بالأعمدة: م، الاسم، البرنامج، الرقم الأكاديمي، الجنس، التخصص، الدفعة، المعدل، التقدير، عام التخرج، رقم الشهادة، جهة العمل، الوظيفة، رقم التلفون، ملاحظات.
2. من تبويب «البيانات» اختر الملف ثم «استيراد الملف». (قالب فارغ متاح للتنزيل.)
3. ملفات Excel تحتاج اتصالاً بالإنترنت مرة واحدة فقط لتحميل مكتبة القراءة، وبعدها تُخزَّن للعمل دون اتصال. CSV لا يحتاج ذلك.

## الخصوصية
- لا يوجد خادم ولا تتبّع: كل البيانات على جهاز المستخدم.
- **لا ترفع ملف بيانات الخريجين الحقيقي إلى مستودع عام**؛ فيه أسماء وأرقام هواتف. استورده من داخل التطبيق فقط.
- البيانات التجريبية داخل التطبيق وهمية بالكامل.
- خُذ نسخة احتياطية JSON دورياً؛ مسح بيانات المتصفح يحذف السجلات.

## تحديث التطبيق
عدّل الملفات ثم غيّر `VERSION` في `sw.js` (مثلاً `v1.0.1`) وارفعها؛ سيظهر للمستخدمين إشعار «يتوفر إصدار جديد».

## الملفات
`index.html` الواجهة · `img/` الشعارات · `styles.css` التنسيق · `app.js` المنطق · `sw.js` العمل دون اتصال · `manifest.webmanifest` بيانات التثبيت · `icons/` الأيقونات
